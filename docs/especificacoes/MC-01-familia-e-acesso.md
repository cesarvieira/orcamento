## Riscos de implantação

| Risco                                                                                                                                                                                                                                                                                                               | Severidade | Mitigação                                                                                                                                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GOOGLE_CLIENT_ID` configurado em produção sem nunca ter sido testado ponta-a-ponta neste ambiente                                                                                                                                                                                                                  | Média      | Testar o fluxo Google manualmente contra credencial real antes do primeiro deploy com login social habilitado                                                                                                                                                                                                        |
| **Front e API em domínios registráveis diferentes.** O cookie de sessão é `SameSite=Lax`: ele viaja entre subdomínios irmãos (`app.` → `api.` do mesmo domínio), mas **não** entre domínios distintos. O sintoma engana — o login devolve 201 e a requisição seguinte 401, como se a sessão não tivesse sido criada | **Alta**   | Escolher a topologia antes do deploy: subdomínios do mesmo domínio, ou API atrás do mesmo host (`/api` no proxy). Se for inevitável separar domínios, é decisão consciente — exige `SameSite=None; Secure` e revisão de CSRF, e deve virar ADR. Medido em 2026-08-26 simulando com `*.localhost`; ver `.env.example` |
